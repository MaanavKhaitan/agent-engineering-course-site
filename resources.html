Resources — Canonical Reading & Tooling Index

The field moves fast. The best skill is reading primary sources. This is the curated set — favor these over secondary blog summaries.

Read these first (the canon)

  • Anthropic — Building Effective Agents (anthropic.com/research/building-effective-agents). The single best starting point. Workflows vs. agents; the composable patterns (chaining, routing, parallelization, orchestrator-worker, evaluator-optimizer). Referenced heavily in Module 6.
  • Anthropic — Effective Harnesses for Long-Running Agents and Harness Design for Long-Running Application Development (anthropic.com/engineering). The initializer/worker pattern, artifacts-on-disk, bridging context windows. Modules 4, 12, 13.
  • OpenAI — A Practical Guide to Building Agents (the OpenAI agents guide PDF). The complementary lab perspective; guardrails, the Agents SDK model.
  • Anthropic — Effective Context Engineering for AI Agents (engineering blog). Compaction, sub-agents, context as a managed resource. Module 4.
  • Chip Huyen — AI Engineering (book, 2024/25) and her blog. The best systems-level treatment of building on foundation models, incl. evals.

By topic

Foundations / prompting

  • Anthropic prompt engineering docs (platform.claude.com/docs). Prompt caching, structured outputs, tool use.
  • Karpathy — Let’s build the GPT Tokenizer (YouTube) for how tokenization actually works.

Tool use & MCP

  • Model Context Protocol docs (modelcontextprotocol.io). The spec, SDKs, and the ecosystem of servers.
  • Provider tool-use docs (Anthropic tool use; OpenAI function calling).

Context & memory

  • Anthropic context-engineering and memory-tool docs.
  • Papers: Memory in the Age of AI Agents (survey); MemGPT / Letta (memory hierarchies for agents).

Retrieval / RAG

  • In Defense of RAG in the Era of Long-Context Language Models (arXiv 2409.01666) — when retrieval still wins.
  • Anthropic — Contextual Retrieval (engineering blog). A strong practical RAG improvement.
  • Search-R1 / ReSearch / DeepResearcher papers — RL-trained agentic retrieval (the frontier of RAG).

Frameworks

  • LangGraph docs (langchain-ai.github.io/langgraph) — graph state machines, checkpointing, persistence.
  • OpenAI Agents SDK docs — handoffs, guardrails, sessions.
  • Claude Agent SDK docs (platform.claude.com) — tool use, hooks, subagents, skills, MCP; and the Managed Agents surface.
  • CrewAI, Google ADK, Pydantic AI, Mastra (TS) — read the quickstarts to feel the design spectrum.

Evals

  • Braintrust docs & blog — eval-driven development, CI gating, trace→eval flywheel.
  • OpenAI Evals and Anthropic eval guidance.
  • SWE-bench (the canonical coding-agent benchmark) — read how a task is scored.
  • Hamel Husain — Your AI Product Needs Evals (blog). The practitioner classic.

Observability

  • Langfuse (open source; self-hostable), LangSmith (LangChain-native), Braintrust, Arize Phoenix, Laminar. Read each landing page + tracing quickstart.
  • OpenTelemetry GenAI semantic conventions — the emerging standard for LLM/agent telemetry.

Reliability & cost

  • Provider prompt-caching docs (the economics section especially).
  • Provider rate-limit / batch / streaming docs.

Security

  • OWASP Top 10 for LLM Applications and OWASP Top 10 for Agentic Applications (2026) — prompt injection, excessive agency, memory poisoning, system-prompt leakage, etc. The reference for Module 11.
  • Simon Willison’s blog — the best ongoing writing on prompt injection (“the lethal trifecta”) and agent security.
  • Google — Agent security / A2A papers; SoK: The Attack Surface of Agentic AI (arXiv).

Deployment & durable execution

  • Temporal docs and their “Temporal for AI” material — durable execution for agents (used by OpenAI Codex, Replit, etc.).
  • LangGraph persistence/checkpointing docs; LangGraph Platform.
  • Anthropic Managed Agents docs — a hosted approach to running the loop + sandbox.

Frontier / long-running

  • METR — Measuring AI Ability to Complete Long Tasks (the time-horizon-doubling result).
  • Geoffrey Huntley — Ralph Wiggum as a “software engineer” (the outer-loop meme) and HumanLayer’s A Brief History of Ralph.
  • Computer-use docs (Anthropic computer use; OpenAI computer-using-agent).

How to keep up

  • Follow the engineering blogs of Anthropic, OpenAI, LangChain, and the eval/observability vendors.
  • Read METR’s evaluations for capability trends.
  • When a new framework/tool trends, read its quickstart and its “why” page, then map it onto the concepts in this course — you’ll usually find it’s a repackaging of patterns you already know.
